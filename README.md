# Homebrew Tap for OmniVault

Official Homebrew tap for [OmniVault](https://github.com/NightKnight24/OmniVault), the native macOS Apple Silicon retro gaming preservation hub.

## Installation

To install OmniVault via Homebrew:

```bash
brew tap NightKnight24/omnivault
brew install --cask omnivault
```

## Updating

```bash
brew update
brew upgrade --cask omnivault
```

## Uninstalling

```bash
brew uninstall --cask omnivault
```
